Recipe table builder

Turns a recipe page into a Cooking-for-Engineers-style table: ingredients top to bottom in the order they're used, steps merging them left to right into one finished dish. Everything below runs in this tab — the recipe is fetched by this site (most recipe pages have no CORS header for the browser to fetch it directly), but the rearranging is done by an LLM endpoint you point this at, and that endpoint's address and key never leave your browser.

1. LLM endpoint

Any OpenAI-compatible chat-completions endpoint: a local server (Ollama, LM Studio, llama.cpp) or a hosted one. Saved to this browser's local storage only.

2. Recipe URL

Paste a link to a recipe page that publishes schema.org Recipe data (most modern recipe sites do — it's what gives Google its rich-result card). Fetching the page and asking the model to rearrange it both happen on this one click.
