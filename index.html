Mimir Widgets

Small oEmbed-enabled widgets, built to embed cleanly into Mimir — drop a bare widget URL into a block and it renders as a live card, not just a link.

Countdown

Live example — pass ?date= (ISO 8601) and ?label=.

Pomodoro

Live example — pass ?work= and ?rest= in minutes.

Timer

Live example — an Apple Watch-style countdown: tap a preset or type your own duration, and it rings a bell when it hits zero. Pass ?presets= as a comma-separated list. Bare numbers are minutes; 45s, 1:30, 1:30:00, 2h and compound units like 1h09m all work too, in the presets and in the custom field alike.

Weather

Live example — pass ?lat= and ?lon=, and optionally ?label=. Shows the coming hours (temperature, precipitation chance, condition icon) via Open-Meteo.

Color

Live example — paste a colour in any CSS syntax and read it back in every other: hex, rgb(), hsl(), hwb(), oklch(), oklab(), lch(), lab() and color(display-p3 …), each a click away from the clipboard. Pass ?c= (url-encode the # as %23). A colour wider than sRGB — an oklch() outside the box — is kept intact, with the rows that can't hold it marked as clipped.

Currency

Live example — converts one currency into another and sketches the last 30 days as a sparkline. Pass ?from=, ?to= (ISO codes) and ?amount=. The amount is editable in place and the arrows flip the direction, both without refetching. Rates come from Frankfurter, which blends 84 central-bank sources and needs no key.

Departures

/train?from=Amsterdam%20Centraal&to=Utrecht%20Centraal&at=08:15&key=YOUR_KEY — a live Dutch Railways departure board for one route: departure and arrival times, delays, platforms and transfers, refreshed every minute. Pass ?from= and ?to= (station name or code), ?at= (HH:MM, omit for the next departures), ?arrive=1 to treat that time as an arrival deadline, ?n= (1–6 departures) and ?label=. Times are always Dutch local time, whoever is reading. Bring your own free key from the NS API portal — it travels in the URL, so treat any note holding one as holding the key itself.

Calculator

Live example — a plaintext calculator: type an expression ending in = or : and press Enter to fill in the result, e.g. 1 + 1 =. Variables persist across lines. Ported from QuickMathJS.

Hike

Build one from a GPX file — draws a recorded hike on a map. The whole track is compressed into the URL's ?t= parameter, so nothing is uploaded and nothing is stored server-side: the note holding the link holds the data. Basemap tiles are proxied through this site, so the tile server never sees who is looking at your route. Also takes ?label=, ?km=, ?g= (metres climbed) and ?d= (minutes).

Dummy Outline

Live example — generates dash-prefixed outline blocks (two spaces per level of indent) from public-domain literature, with a copy button. Pass ?blocks= (1–200) and ?depth= (0–5).

Want to build your own widget that embeds just as well? Read SKILL.md — it's written so you can hand it straight to an LLM and get a Mimir-friendly oEmbed widget out the other end.
